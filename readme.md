#  GalaxyTours
 Este é um projeto desenvolvido para a avaliação de Front-End, focado no css para um app de uma empresa que faz viajens ao espaço.No css está resolvido problemas de responsividade como o tamanho da tela do celular e do tablet.

##  Tecnologias Utilizadas
* HTML5 (Semântica e Acessibilidade)
* CSS3 (Estilização e Feedback Visual)
* JavaScript (Manipulação de DOM e Eventos)

##  Estrutura do Projeto
O projeto foi organizado seguindo boas práticas de mercado:
/
├── index.html
└── src/
    ├── styles/  (Estilos da página)
    ├── scripts/ (Lógica de interação)
    └── images/  (Ativos visuais)
